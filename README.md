** Python Fundamentals with Student Performance Analysis**
**Project Overview**

This project is part of my Python and Data Science learning journey. It focuses on understanding fundamental Python programming concepts through hands-on practice and implementing a simple Student Performance Analysis mini-project.

The project demonstrates how basic Python concepts can be applied to perform calculations, organize information, and analyze student marks.

**Objectives**

- Understand Python programming fundamentals.
- Explore different data types and data structures.
- Implement conditional statements and loops.
- Develop reusable functions.
- Learn basic file handling operations.
- Apply Python concepts to a practical mini-project.

** Concepts Covered**

1. Variables and Data Types
2. Lists and Dictionaries
3. Conditional Statements (if-else)
4. For and While Loops
5. Functions
6. File Handling (Read and Write)
7. Basic Data Analysis

** Mini Project: Student Performance Analysis**

A simple Python application designed to analyze student marks using fundamental programming concepts.

** Features**
- Store student marks using Python lists.
- Calculate total and average marks.
- Identify highest and lowest scores.
- Display individual student scores.
- Generate a basic student performance report using file handling.
